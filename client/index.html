SQL 转 ER 图在线工具 - 自然语言生成陈式ER图与功能结构图

sql2er 是免费的在线数据库建模工具：粘贴 SQL 建表语句（MySQL）或自然语言需求描述， 自动生成陈式（Chen）ER 图，包括实体矩形、属性椭圆、主键下划线、联系菱形与 1/N/M 基数标注； 也支持输入系统描述或 Markdown 大纲，一键生成系统功能结构图。 支持智能布局、环形网格、力导向、分层四种布局算法，可导出 draw.io、PNG、SVG，无水印、无付费墙、无需注册登录。

核心功能

  • SQL 转 ER 图：解析 CREATE TABLE 语句，提取表名、中文注释、主键、外键与多对多关联表
  • 自然语言生成 ER 图：输入业务需求描述，AI 生成实体、属性与联系
  • AI 补全：基于现有图推断缺失联系与属性
  • 功能结构图：结构树编辑、缩进/Markdown 大纲解析、AI 生成模块层级
  • 导入导出：导入 .drawio 文件，导出可编辑 .drawio、高清 PNG、矢量 SVG

常见问题

  • 怎么把 SQL 表结构画成 ER 图？—— 粘贴建表语句（含 COMMENT 中文注释效果最佳），自动生成可拖拽编辑的陈式 ER 图并导出。
  • 支持哪些数据库方言？—— 以 MySQL 语法为主，兼容常见 CREATE TABLE / ALTER TABLE 外键写法。
  • 是免费的吗？—— 免费，无水印、无付费墙、无登录。
